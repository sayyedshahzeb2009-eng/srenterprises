# SR Enterprises — Premium Furniture Website

A responsive, editorial-style four-page furniture brand website for SR Enterprises, Mumbai.

## Pages
- `index.html` — Home, featured categories, product highlights, FAQ and contact CTA
- `collections.html` — Sofas, chairs, beds, tables and living accents
- `about.html` — Brand story and design values
- `contact.html` — Contact details, Instagram and enquiry form interface

## Publish with GitHub Pages
1. Open the repository: https://github.com/sayyedshahzeb2009-eng/srenterprises
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to finish deploying. The expected site URL is https://sayyedshahzeb2009-eng.github.io/srenterprises/

If your default branch is not `main`, select the branch shown in the repository.

## Before taking customer orders
- Replace sample product photos with approved product photography.
- Add real product prices, dimensions, materials, availability and delivery/return policies.
- Add your business phone/WhatsApp number.
- The contact form is currently a front-end demo and does not submit to a database or business inbox. Connect a form service or backend before relying on it for enquiries.
- This is a product showcase and enquiry site, not a checkout-enabled ecommerce store.
- Images and Google Fonts are loaded from external services, so an internet connection is required.
